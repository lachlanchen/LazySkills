LazySkills 是 [lachlanchen](https://github.com/lachlanchen) 為 LazyingArt 工作流整理的可重用 Agent 技能庫。

目前的核心技能是 `lalachan-xyq-browser-video`：透過已登入的 Chrome/CDP 瀏覽器介面操作小雲雀，驗證模型、時長、比例、素材與積分，再下載輸出影片並同步到發布資料夾。
