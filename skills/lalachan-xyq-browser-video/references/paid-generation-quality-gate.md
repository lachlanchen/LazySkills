# Paid Generation Quality Gate

## Preflight Evidence

Before a paid click, save a screenshot and inspect the visible page or DOM for:

- workflow or mode;
- actual selected model row and tier;
- duration and ratio;
- every required uploaded preview in the intended order;
- filled prompt;
- displayed credit cost and current balance;
- automatic generation countdown disabled.

Values written inside the prompt and statements made by an Agent are not proof
of the renderer's configuration. Stop when any field is missing,
contradictory, or cannot be shown.

For Agent/storyboard workflows, inspect the real editor before final render.
Reject a drifted style, duration, shot count, or main-character mapping.

## Acceptance Evidence

After a paid result:

1. Download only from the current result card.
2. Verify duration, dimensions, audio stream, and a complete ffmpeg decode.
3. Create a contact sheet.
4. Inspect main-character identity, duplicates, visual style, setting, and key
   story beats.

For LALACHAN, generic replacement people or mascots, duplicate leads, incorrect
reference mapping, missing required cast, or a switch away from the requested
figurine style fail acceptance.

Do not publish a rejected result. Retry only after explicit user approval and a
report of observed charge, remaining balance, failure evidence, and least-cost
recovery.

## Multi-Clip Recovery

Before starting, show the total visible cost. Generate and accept the first clip
before paying for the second. Stop if the first clip fails. Concatenate only
accepted clips.
